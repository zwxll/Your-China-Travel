# 记忆书架翻页集成设计

## 目标

直接增强现有记忆书架：保留省份书架、3D 选书、封面、省份编辑和当前数据结构，将打开省份书籍后的城市章节与照片阅读体验升级为温暖、克制、可真实翻页的中文摄影书。

## 范围

- 允许修改 `index.html` 中的记忆书架模块。
- 允许在 `assets/memory-flipbook/` 新增局部 CSS、JavaScript、纹理、字体和第三方运行时许可证。
- 使用 `create-photo-flipbook-ui` 自带的 2D PageFlip 运行时和摄影书视觉资产为基线。
- 不改变 Supabase、IndexedDB、OSS、城市资料或省份封面的持久化方式。
- 不改写旅行照片，不复制旅行数据，不虚构日期、地点、行程或游记。

## 保留的现有流程

1. 用户打开“记忆书架”。
2. 用户在 3D 书架中拖动、旋转和选择省份书籍。
3. 用户点击省份书籍，封面播放现有打开动画。
4. 用户在城市章节页选择城市。
5. 用户进入城市照片阅读器。
6. 返回按钮和 `Escape` 依次返回城市章节、省份书架和主页。

省份选择、书架 WebGL/DOM 回退、省份编辑及封面保存逻辑保持不变。

## 增强后的城市章节

`memoryOpenChapters(province)` 保留现有数据和导航职责，只调整呈现：

- 左页使用省份封面、布面色和温暖纸张构成省份扉页。
- 右页将城市列表排成目录，保留城市名、已有日期和照片数量。
- 缺失日期继续显示“时间尚未记录”。
- 焦点、键盘选择和封面预览行为保留。

## 增强后的城市照片阅读器

`memoryOpenAlbum(province, city)` 继续通过 `getPhotosByCity(city.cityKey)` 读取当前照片，但将现有两张静态页面和手写分段动画替换为 PageFlip 实例。

书页顺序：

1. 城市扉页：城市名、已有日期、照片数量和已有简介。
2. 若无简介，仅显示“城市简介尚未记录”，不生成代替文案。
3. 照片页：依原始顺序安排为单图、双图、竖图和小图留白版式。
4. 结束页：只显示现有统计与“更多记忆尚未记录”。
5. 首尾页为硬质页，中间页为可翻软页。

照片仍可单击打开现有原图查看器。现有“城市详情”和“返回省份章节”按钮保留。首轮集成不保留相册内的拖动调整构图，因为该手势与翻页拖动冲突；原图查看不受影响。

## 视觉方向

- 气质：温暖、安静、私人化的旅行纪念册。
- 材质：低对比度布面、暖白纸张、轻微纸纹和柔和书脊阴影。
- 字体：中文优先复用现有 `Noto Serif SC`，英文与数字使用 Source Serif 4，控件使用现有无衬线字体。
- 排版：照片为主，文字为辅，使用尺度、留白和页面节奏而非额外装饰。
- 色彩：米白、浅麻灰、墨青和少量陶棕，与现有书架界面衔接。

`memory-flipbook.js` 对外只提供创建和销毁阅读器所需的最小入口，不持有旅行数据。`index.html` 负责把现有 `memoryShelfState` 和照片数组转换成书页 DOM。

## 状态与生命周期

- `memoryShelfState` 仍是唯一状态来源。
- 进入城市相册时创建 PageFlip 实例，返回章节、关闭书架或重建相册时显式销毁。
- 转页事件回写 `memoryShelfState.page`，页码和上一页/下一页按钮与运行时同步。
- 加载新城市时先销毁旧实例，防止重复监听、画布残留或内存泄漏。
- 图片加载失败时保留书页尺寸并显示“影像暂无法加载”。

## 响应式和输入

- 桌面宽屏显示双页，保留中缝和纸张阴影。
- 屏幕宽度不足时切换单页，不缩小两页硬塞进手机屏幕。
- 支持点击页角、鼠标拖动、触摸滑动、左右方向键和上一页/下一页按钮。
- 页面中的照片按钮保持键盘可达，翻页时不让隐藏页中的控件进入 Tab 顺序。
- `prefers-reduced-motion` 模式下减少翻页时长，但保留清晰的页面状态变化。

## 验收条件

1. 现有省份书架、3D 选书、封面打开、省份编辑和返回流程保持可用。
2. 任意有照片的城市可打开真实翻页阅读器，且页面数与当前照片数据匹配。
3. 无日期、无简介、无照片和图片加载失败状态均有可理解的呈现，无虚构内容。
4. 照片可打开原图查看器，城市详情入口正常。
5. 桌面双页和手机单页均可完成首页到尾页的阅读。
6. 鼠标、触摸、键盘、按钮和减少动画模式均经验证。
7. 浏览器控制台无相关错误，打开和关闭多个城市相册后无重复实例。
8. 现有 `tests/local-folder.spec.cjs` 继续通过，新增的 `tests/memory-flipbook.spec.cjs` 覆盖章节、翻页和返回流程。

## 非目标

- 不重做整个记忆书架或主站 UI。
- 不改造其他顶栏、地图、城市卡片、时间轴或照片查看器。
- 不引入包管理器、构建工具或远程 CDN。
- 不进行 AI 修图、生成旅行照片或生成游记。
- 不在首轮集成中同时解决照片构图拖动与翻页手势的冲突。
