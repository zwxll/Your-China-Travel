# 记忆书架翻页原型设计

## 目标

在不修改现有 `index.html` 的前提下，于 `prototypes/memory-flipbook/` 建立一个可独立预览的中文旅行摄影书原型。原型用于验证“从现有省份书架打开后，进入真实翻页阅读”的视觉和交互方向，不承担正式集成。

## 已确认范围

- 使用 `create-photo-flipbook-ui` 自带的 2D HTML 翻页运行时为基线。
- 仅在 `prototypes/memory-flipbook/` 内新增原型文件。
- 不修改 `index.html`、现有旅行数据、图片原件或书架逻辑。
- 保留未来与现有省份书架、3D 选书、封面、编辑功能和数据结构对接的边界。
- 原型支持桌面双页、手机单页、鼠标拖动、触摸和左右方向键翻页。
- 内容不虚构日期、景点、行程或游记；缺失字段使用留白或“尚未记录”。

## 原型数据

选用湖北省的孝感市作为原型章节。这是当前资料中媒体最多的城市：10 张图片、3 段视频，但无游玩日期、简介和评价。

原型只读取以下来源：

- `旅行资料/旅行资料/未分类/孝感市/info.json`
- `旅行资料/旅行资料/未分类/孝感市/photos/`

不根据图片内容推断具体地点。明显的工具图、流程图和重复图片不进入主编排；原文件保留不变。视频不在首个原型中嵌入，书末只显示“3 段影像尚未收录”，避免扩大运行时范围。

## 视觉方向

- 气质：温暖、安静、私人化的旅行纪念册。
- 材质：低对比度布面封皮、暖白纸张、轻微纸纹、柔和书脊阴影。
- 字体：中文衔接现有的 `Noto Serif SC`，英文与数字使用运行时附带的 Source Serif 4，控件使用简洁无衬线字体。
- 排版：照片为主，文字为辅；通过单图、对页、小图留白和空白页建立节奏。
- 色彩：米白、浅麻灰、墨青和少量陶棕；不增加高饱和装饰色。

## 书页结构

1. 布面封面：“湖北省·旅行记忆”，不显示未记录的日期。
2. 封里：纯材质页，不填充虚构文字。
3. 章节扉页：“孝感市”，辅助信息显示“时间尚未记录”。
4. 摄影跨页：从非重复、非工具图的图片中按原始顺序编排。
5. 留白过渡页：只用章节名或页码，不生成游记。
6. 书末页：如实列出照片数量、未收录视频数量和“城市简介尚未记录”。
7. 封底：纯布面。

## 技术结构

`prototypes/memory-flipbook/` 保持自包含：

```text
prototypes/memory-flipbook/
├─ index.html
├─ flipbook.js
├─ styles.css
├─ html-contract.test.mjs
├─ README.md
├─ assets/
│  └─ photos/
├─ style/
│  ├─ book-style.css
│  ├─ paper-grain.svg
│  ├─ cloth-weave.svg
│  └─ fonts/
└─ vendor/
   ├─ page-flip.browser.js
   └─ PAGE-FLIP-LICENSE
```

以 skill 自带运行时为起点，只修改原型目录内的 HTML/CSS/JS。照片复制到原型的 `assets/photos/`，使预览不依赖跨目录路径。不引入新的包管理器、构建步骤或远程 CDN。

## 交互与响应式

- 桌面端默认显示双页，保留中缝和纸页阴影。
- 屏幕宽度不足时自动切换为单页，不仅缩小双页。
- 点击/拖动页角、水平触摸手势以及左右方向键均可翻页。
- 页码和“上一页/下一页”按钮作为明确的非拖动入口。
- 开启 `prefers-reduced-motion` 时缩短或取消翻页动画，但不移除页面状态反馈。
- 图片使用 `contain` 或经明确容器裁切，不改写原图。

## 错误和缺失数据

- 照片加载失败时保留页面尺寸，显示“影像暂无法加载”。
- 没有日期、简介或评价时，不用推断值替代。
- JavaScript 不可用时，页面仍以顺序 HTML 显示封面与书页内容。

## 验收与验证

1. 运行 `node --test html-contract.test.mjs`，确认只有首尾页使用硬质页、书页顺序和结构符合运行时约定。
2. 使用本地 HTTP 服务预览，不依赖 `file://`。
3. 在桌面宽屏和手机窄屏各验证一次封面、章节页、照片跨页和书末页。
4. 验证点击、拖动、触摸模拟、键盘翻页、边界页锁定和减少动画模式。
5. 检查浏览器控制台，不得有与原型相关的错误。
6. 检查 Git 变更，确认 `index.html` 和旅行资料原文件未改动。

## 非目标

- 本阶段不将原型嵌入正式记忆书架。
- 不改造现有单文件应用架构。
- 不新增照片编辑、上传、删除或云同步功能。
- 不对照片做 AI 修图、补图或重新着色。
- 不使用语义照片搜索引擎；当前数量可直接审阅。

## 后续集成边界

原型获得确认后，正式集成应以现有 `memoryShelfState` 为唯一状态来源：省份对应一本书，城市对应章节，媒体对应书页。翻页运行时只负责呈现和导航，不复制、持久化或改写旅行数据。进入阅读时暂停书架动画，退出时销毁翻页实例并恢复原书架状态。
