# 记忆书架海报分享设计

## 目标

用户在记忆书架中点击一次“分享书架”，网站生成一张可保存的微信分享海报。海报包含记忆书架主题画面和二维码；其他人扫码后无需登录，直接进入只读版记忆书架，并可按省份、城市浏览生成海报时已经保存的照片。

## 已确认范围

- 一次分享整个记忆书架，不单独选择省份、城市或照片。
- 交互保持简单，不向用户暴露令牌、权限或有效期设置。
- 分享内容采用生成海报时的快照；以后新增或删除的内容不会自动改变旧快照。
- 用户再次生成海报时覆盖自己的上一份快照，原二维码继续指向更新后的书架。
- 分享页只展示照片，不包含视频。
- 任何拿到二维码或链接的人都能查看，不要求登录或输入密码。
- 访客只能浏览，不能编辑、删除、上传或进入分享者账号功能。

## 用户流程

1. 已登录用户打开记忆书架。
2. 点击右上角“分享书架”。
3. 页面先确保当前照片已经同步到私有 OSS，再发布一份只读书架快照。
4. 页面生成并预览 1080 × 1440 PNG 海报，内容包括标题、城市/省份/照片统计、代表封面以及二维码。
5. 用户点击“保存海报”，再发送到微信好友或朋友圈。
6. 接收者扫描二维码，进入 `https://zwxll.github.io/Your-China-Travel/?memoryShare=<share-id>`。
7. 页面自动进入只读记忆书架，可翻阅省份书籍、城市章节和照片册。

若用户未登录、书架为空、当前页面不是可公开访问的 HTTPS 部署，或同步/发布失败，不生成无效海报，并显示明确提示。

## 数据与接口

新增 `public.memory_shelf_shares` 表，每个用户最多一行：

- `user_id uuid primary key`：分享者，删除账号时级联删除。
- `share_id uuid unique not null default gen_random_uuid()`：二维码中的不可预测公开标识。
- `snapshot jsonb not null`：最小化的只读书架快照。
- `created_at timestamptz not null default now()`。
- `updated_at timestamptz not null default now()`。

表启用 RLS，但撤销 `anon` 和 `authenticated` 的直接权限。浏览器不直接读写该表，所有操作都经过新的 Supabase Edge Function `memory-shelf-share`。

Edge Function 支持两个动作：

- `publish`：必须携带有效 Supabase 登录令牌。校验快照中的每个 OSS 路径都属于 `users/<当前用户ID>/`，清理非必要字段后按 `user_id` upsert，并返回稳定的 `shareId`。
- `read`：不要求登录。按 `shareId` 读取快照，仅为该快照中经过校验的私有 OSS 图片生成短时 GET 签名地址，并返回可渲染数据。

快照只包含渲染记忆书架所需的省份名、评价、月份、城市名、城市说明、照片顺序和 OSS 对象路径。不得包含邮箱、账号 ID、本地文件路径、Data URL、点评隐私字段或视频记录。

## 前端设计

### 分享入口与海报

- 在记忆书架顶栏关闭按钮左侧增加“分享书架”。
- 仅书架拥有者正常登录时可用；公开分享模式中隐藏。
- 点击后显示单一进度状态“正在整理分享海报…”，完成后打开海报预览弹窗。
- 海报采用项目现有纸本与书架主题，不增加另一套视觉语言。
- 海报底部显示“微信扫码 · 翻阅我的旅行记忆”，二维码留出足够白边。
- 操作只保留“保存海报”和“关闭”。再次点击分享会更新线上快照并重新生成海报。

二维码由固定版本的浏览器端 QR 库生成，二维码内容使用 `supabase-config.js` 中的正式分享根地址，避免在本地调试时生成 `file://` 或局域网地址。

### 只读分享模式

- URL 含合法 `memoryShare` 参数时，不读取访问者的本地旅行资料，不触发登录或云端恢复。
- 页面从 `memory-shelf-share` 读取公开快照，将返回数据适配为现有 `memoryShelfState.provinces` 结构，复用现有书架、城市章节、照片册和全屏照片查看器。
- 隐藏编辑省份、城市详情、上传、删除、账号、资料文件夹和生成分享海报等入口。
- 页面标题和说明改为“旅行记忆书架”“扫码分享的只读旅行相册”。
- 无效、缺失或已删除的分享显示独立空状态，不回退到访问者自己的本地数据。

## 安全边界

- 阿里云 OSS Bucket 继续保持私有，二维码中不包含 OSS 地址。
- `publish` 不信任客户端提供的路径，必须验证路径归属当前登录用户。
- `read` 只对数据库快照里列出的路径签名，不能接受调用者额外传入任意对象路径。
- OSS 签名保持短时有效；分享页面刷新时重新向 Edge Function 获取。
- `SUPABASE_SERVICE_ROLE_KEY`、阿里云密钥只能存在于 Edge Function 环境变量中。
- 公开快照不包含 Data URL，避免数据库记录过大。
- 单次快照设置合理的省份、城市和照片数量上限，超限返回可理解的错误，防止匿名读取接口被滥用。

## 错误与降级

- 未登录：提示“登录后才能生成分享海报”。
- 没有照片：提示“记忆书架中还没有可分享的照片”。
- 照片尚未上传：先执行现有云同步；失败则停止发布，不生成残缺二维码。
- QR 库加载失败：保留分享链接复制能力作为错误恢复入口，但不生成空白海报。
- 某张图片临时签名失败：公开读取整体失败并显示重试，不静默展示缺图书架。
- Canvas 导出失败：保留海报预览和分享链接，提示用户截图或重试。

## 验收标准

- 已登录且有照片的用户可从记忆书架生成一张可下载 PNG 海报。
- 微信或普通浏览器扫描二维码后，无需登录即可进入完整的只读记忆书架。
- 访客可依次进入省份、城市章节和照片册，并可全屏查看照片。
- 分享页没有任何编辑、删除、上传、登录或本地资料入口。
- 生成海报后新增照片不会自动出现在分享页；再次生成海报后出现。
- 公开接口无法读取其他用户未发布的快照，也无法为快照外 OSS 路径签名。
- 私有 OSS ACL、现有登录同步和本地模式行为保持不变。

## 非目标

- 不接入微信 JS-SDK、小程序或“一键发送给微信好友”。
- 不提供访问密码、有效期、访客统计、评论、点赞或逐张选择。
- 不分享视频。
- 不重构现有单文件前端，也不改变记忆书架现有交互与视觉结构。
